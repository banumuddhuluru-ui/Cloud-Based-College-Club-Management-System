Cloud-Based College Club Management System
📌 Project Description
The Cloud-Based College Club Management System is a web application designed to manage college clubs, members, events, and event registrations in one place. Firebase Realtime Database is used to store and retrieve data dynamically.
🚀 Features
- 📊 Dashboard with club, member, event, and registration counts
- 🏫 Add and manage college clubs
- 👥 Add and manage club members
- 📅 Create and manage club events
- 📝 Register students for events
- ☁️ Store data using Firebase Realtime Database
- 📱 Responsive and user-friendly interface
- 🗑️ Delete clubs, members, and events
🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Application functionality
- Firebase Realtime Database – Cloud data storage
- Firebase Analytics – Application analytics

⚙️ How to Run
1. Download or clone this project.
2. Open the project folder in VS Code.
3. Make sure the three files are present:
   - index.html
   - style.css
   - script.js
4. Open index.html using Live Server.
5. The application will open in your browser.
6. Add clubs, members, events, and registrations.
7. The information will be stored in Firebase Realtime Database.
☁️ Firebase
This project uses Firebase Realtime Database for cloud-based data storage.
Firebase stores:
- Clubs
- Members
- Events
- Registrations
🎯 Objective
The main objective is to provide a simple digital platform for colleges to organize club activities, manage members, conduct events, and maintain registrations efficiently.
